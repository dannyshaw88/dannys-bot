---
name: Dashboard cycle summary icons
description: Dashboard cycle-complete activity summaries reuse Statistics action icons while eye-based metrics remain text-only.
---

Dashboard cycle summaries should show the matching Statistics icons for follows, likes, DMs, posts, shares, Reels, and feed scrolling. Do not add icons for story, feed, or explore metrics that are represented by eye indicators in Statistics.

**Why:** The user wants activity stamps to be visually scannable without duplicating or changing the eye-based view indicators.

**How to apply:** Keep this presentation display-side so historical activity rows gain the same treatment; preserve the stored summary wording and existing ticker text.
